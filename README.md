# AI Medical Diagnosis Risk Management Framework

SEP CIAP Micro Project — SDG 3: Good Health and Well-Being

## Prototype purpose
This is an educational software-engineering prototype that identifies and evaluates risks associated with an AI-based medical diagnosis system. It is **not** a medical diagnosis tool.

## Features
- Risk register
- Likelihood × Impact scoring
- Low/Medium/High/Critical classification
- Technical, ethical and healthcare risk categories
- Mitigation recommendations
- Human verification check
- Privacy, bias, explainability and authentication governance checks
- Streamlit dashboard

## Run locally

1. Install Python 3.11 or 3.12.
2. Open a terminal in this folder.
3. Create a virtual environment:
   `python -m venv venv`
4. Activate it on Windows:
   `venv\Scripts\activate`
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start the application:
   `streamlit run app.py`

The browser should open the Streamlit application automatically.
